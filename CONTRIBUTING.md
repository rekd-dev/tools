# Contributing

This repository is public so you can read it, fork it, and use it under the [MIT License](LICENSE). That is the whole invitation.

**Unsolicited pull requests and drive-by issues are not reviewed.** The default is a closed contribution list. If I want help on something, I will ask or add you as a collaborator.

If you fork, you do not need permission. Keep the copyright notice.

If you have a security report, see [SECURITY.md](SECURITY.md).
